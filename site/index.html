An agent that can prove what it did.

Somnus reads live order books, forms its own probability estimates, and trades inside hard limits. Every decision, order and rule change goes into a signed hash chain — so you never have to take its word for anything, including the losses.

What it does

Three things, and it shows the evidence for all of them.

Prices its own opinion

Driftless GBM with horizon-matched volatility, not naive sqrt-scaling. It compares that to the book and acts only where there is genuine edge — which most cycles means not at all.

Point your agent at it

Trusts only what it measured

Each window length is scored against its own base rate. One-minute windows are blocked outright — 3,110 samples said they were no better than a coin flip.

Open the tier table

Refuses on its own terms

Daily loss, drawdown, loss streak, execution failures, stale data, clock drift, a dead book feed. Enforced server-side, and the reason is always recorded.

Verify

Do not take its word for anything. Check it yourself.

Every entry carries the hash of the one before it, and most are signed by the wallet that placed the trades. The endpoint takes no key — an audit that needs the operator's secret is not an audit — so this works from your terminal right now. 

curl -s -X POST https://somnus-backend.onrender.com/api/proof/verify \
  -H 'content-type: application/json' -d '{}'

What it answered on 5 September 2026

linkage, every entry          PASS    2,885 checked
recomputed head matches       PASS
signatures valid              PASS    400 of 400
older signatures out of scope 2,399 — pageable
unsigned historical entries   152 — reported, not hidden
signer                        0xC2187C19bcD588E0eb68d68143Af5D410079C69a

Signature recovery costs about 36 ms an entry, so one request checks linkage over everything and signatures over the most recent 400, reporting exactly what it skipped. That limit exists because leaving it off made a single anonymous request cost 78 seconds of CPU — found while auditing this project, and fixed rather than hidden.

Browse the chain

Set up · about 30 seconds

There is no dashboard. Your coding agent is the interface.

Somnus speaks MCP, so you point whatever you already code in at one URL and ask in English. Twelve read-only tools need no credential. Add an x-somnus-token header and seven more appear, backed by a wallet derived from that token — the same token always returns the same wallet, and none of it is stored. Use a long random string and keep it like a password. Testnet only.

Every one of these is really just pointing at https://somnus-backend.onrender.com/mcp. For a client that only speaks stdio, bridge it: npx -y mcp-remote https://somnus-backend.onrender.com/mcp.
